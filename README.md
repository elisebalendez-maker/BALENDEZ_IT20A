Sorting Algorithms in Java

Program Description

This Java program kay nag-implement og tulo ka sorting algorithms, ang una kay Bubble Sort, dayun Selection Sort, ug Insertion Sort. Ang each algorithm kay naay own nga method nga gigamit sa pag-arrange sa mga numbers gikan sa pinakagamay hangtod sa pinakadagko nga numbers.

Sorting Algorithms

1. Bubble Sort

Ang Bubble Sort kay nag-compare og duha ka magka dikit nga numbers. Kung mas dako ang unang number kaysa ikaduha, ilang ibaylo ang ilang positions. Balik-balikon ra ni nga process hangtod ma-arrange na ang tanan numbers.

2. Selection Sort

Ang Selection Sort kay mangita sa pinakagamay nga number sa wala pa ma-sort nga part sa array. Dayon, ibalhin dayun ni sa sakto nga position through swapping. Balik-balikon kini hangtod ma-sort na ang tanan numbers.

3. Insertion Sort

Ang Insertion Sort magkuha og isa ka number then pangitaon ang sakto nga position ani, dayun I-compare ni niya sa mga numbers nga naa na sa sorted part, ug ibutang ni sa position kung asa siya dapat. Balik-balikon rani niya nga process hangtod sa ma-arrange na ang tanan numbers.

Differences Between the Three Sorting Algorithms

- Bubble Sort – Nag-compare og magkadikit nga numbers ug mag-swap kung sayop ang ilang order.
- Selection Sort– Mangita sa pinakagamay nga number ug ibutang kini sa sakto nga position.
- Insertion Sort– Magkuha og usa ka number matag higayon ug isulod kini sa sakto nga position.

Parehas ra sila nga nag-arrange sa numbers gikan sa pinakagamay hangtod sa pinakadako, pero lahi-lahi ang ilang mga process.

Reflection Questions

1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang tulo ka algorithms nag-arrange sa numbers gikan sa pinakagamay hangtod sa pinakadako. Ang Bubble Sort nag-compare ug nag-swap sa magkadikit nga numbers. Ang Selection Sort mangita sa pinakagamay nga number ug ibutang kini sa sakto nga position. Ang Insertion Sort magkuha og usa ka number matag higayon ug ibutang kini sa hustong lugar. Ang ilang kalainan naa sa paagi sa pag-compare ug pagbalhin sa numbers.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay simple ra ang proseso niini. Mag-compare ra og duha ka magkadikit nga numbers ug mag-swap kung kinahanglan. Sayon pud sundon kay balik-balikon ra ang same process hangtod ma-sort ang tanan numbers.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Insertion Sort ang mas maayo kung sorted na daan ang numbers. I-compare na lang niini ang matag number sa naunang number ug dili na kinahanglan magbalhin-balhin og elements. Tungod niini, mas paspas ang iyang process kung naa na sa sakto nga order ang array.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung magdugang og numbers sa array, mas daghan na ang kinahanglan i-compare ug i-arrange sa algorithms. Mahimong mas dugay ang ilang sorting process, labi na kung daghan na kaayo ang numbers. Ang Bubble Sort ug Selection Sort mahimong mas mohinay tungod sa daghang comparisons, samtang ang Insertion Sort mas maayo kung hapit na sorted ang numbers.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Isip future programmer, importante nga masabtan ang lain-laing sorting algorithms kay matag usa naa'y kaugalingong advantages ug disadvantages. Pinaagi niini, makapili ta sa pinakamaayong algorithm depende sa kadaghan ug arrangement sa data. Makatabang pud kini aron mas efficient ug mas maayo ang performance sa atong programs.
